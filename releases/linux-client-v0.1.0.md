# headless Linux client v0.1.0 — rootless trial

The existing reviewed STUNMESH image now has a documented headless laptop deployment and an optional rootless Podman/systemd service. Configuration stays in an external read-only directory. Only `10.77.0.1/32` uses WireGuard; host applications currently reach it through the documented SSH ProxyCommand. Direct host routing and Syncthing startup are later stages.

- **Download:** `stunmesh-linux-amd64.oci.tar` and `SHA256SUMS`. Linux/amd64 only. Load with `podman load`; pin the image ID in the client instructions. No private configuration, signing key, peer key or PSK is included. Peer public keys documented elsewhere in the repository are public metadata.
- **Provenance:** unchanged locally built image, source commit `d4d12e9f2e17f6259fbb496854b7117ac300e6c8`; image ID `sha256:470285618081f8b2ecb049f0b8280a815b9a7d88bbed2c6933ad1e7a34d7d8e8`. Packaging adds no runtime code/dependencies or hosted build/update pipeline. See `ARTIFACT_MANIFEST.json`.
- **Validation:** external rootless Podman 5.4.2 passed authenticated WireGuard, actual SSH including concurrent sessions, SMB 3.02 negotiation, normal internet outside the tunnel, and client restart. The owner also confirmed a real laptop connection. Quadlet generation/unit validation covers service packaging; laptop systemd lifecycle, suspend/roaming/reboot and battery checks remain open. SMB negotiation did not test account credentials or file operations.
- **Scope:** narrow SSH/SMB forwards on the NAS; no general LAN routing, host firewall/default-route change, automatic service installation, or relay fallback. NAT compatibility is limited to tested paths. This is a prerelease, not a claim of completed production acceptance.

See the [client and service instructions](https://github.com/snf/stunmesh-go/blob/linux-client-v0.1.0/deploy/client/README.md), [progress and remaining gates](https://github.com/snf/stunmesh-go/blob/linux-client-v0.1.0/CLIENT_PROGRESS.md), and [credential review](https://github.com/snf/stunmesh-go/blob/linux-client-v0.1.0/SECRET_REVIEW.md).
