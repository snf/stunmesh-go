# Implemented trust boundaries

1. Trusted local configuration chooses WG public identities, PSKs, tunnel addresses and routes. Android ordinary import is public-only. A separately authorized encrypted Android backup is the sole private-key recovery path.
2. STUN learns a reflexive address from the same UDP socket that carries WG. Replies require the configured source, transaction ID, binding-success type and valid bounded attributes; invalid replies do not consume the waiter.
3. OpenDHT publishes version-2 public hints with a 600-second TTL. HTTPS has bounded requests/responses and no redirects. Hints choose only numeric endpoints for already configured peers. Unsolicited private/CGNAT, loopback, link-local and multicast destinations are rejected; no automatic LAN-candidate policy is enabled. Explicit trusted static endpoints are a separate configuration input.
4. WG authenticates the handshake, PSK and transport packets. Neither a STUN reply, successful publication, proxy TLS certificate, QR proposal ID nor VPN icon authenticates a VPN peer.
5. Android keeps one foreground service, one serialized lifecycle owner and one cancellable discovery loop. Physical-network callbacks cancel stale work; offline closes WG sockets/timers; handover rebinds protected outer sockets without replacing the TUN. Stable refresh is 180 seconds with small jitter, capped below four minutes. Failures back off; WG keepalive is independent (default 25 seconds).
6. The server's local UDP proxy feeds the kernel WG interface through per-peer loopback sockets. Source-to-peer mappings change only after bounded hint selection and reject collisions. It does not implement cryptographic authentication. Unknown outer sources are dropped, so remote NAT changes can require another discovery cycle. Existing authenticated sessions are preserved; recovery is not instantaneous and must be measured during the phone trial.

Working-session selection uses WG-reported handshake/receive state, sampled during normal discovery cycles; it adds no phone health timer. It cannot infer exact last-packet time from cumulative counters. Poisoned public discovery can still prevent recovery. A recent handshake is a recent authenticated session, not proof of present reachability.

The desktop daemon has a trusted `wg` executable for public-only metadata reads and typed wgctrl endpoint updates. It does not request `dump`, private-key or PSK fields. A compromised namespace administrator could nevertheless control/read WG state; container privileges and mounts remain part of the trust boundary.
