# Go daemon and mobile-core network/process surface

This is a source-level inventory for audited commit `71a73228cd2bc001cdc5d485a16621a24bfae15a`, checked 2026-09-13. It excludes transitive dependency internals and test-only listeners. `rg` searches over production Go files were followed by manual review of the cited call sites. A missing hard-coded endpoint here is not proof that a dependency cannot communicate.

| Source | Inbound data or outbound destination | Trust boundary |
| --- | --- | --- |
| `internal/mobilebind/bind.go`, `demux.go`, `stun.go` | Android's shared UDP socket receives WireGuard and STUN-shaped datagrams, sends WG packets and STUN probes to configured/resolved addresses. | STUN is an unauthenticated address hint; ordinary WG packets go to wireguard-go. G-01 shows endpoint hints can alter its authorized peer set. |
| `internal/stun/stun_linux.go`, `helper_socket.go`, `stun_darwinbsd.go`, `internal/wgproxy/*` | Desktop STUN probes, raw/UDP reply processing, and optional local UDP relay to the host WireGuard interface. | Raw Linux path lacks source/transaction checks (G-04) and has a one-reply fallback defect (G-16). Local proxy checks both before routing STUN replies. |
| `internal/plugin/builtin/opendht/opendht.go` | HTTPS or HTTP requests to user-configured OpenDHT proxies; responses are public record data. | No STUNMESH peer identity check on public DHT writes. Plaintext timestamp can eclipse a valid record (G-03); redirects and unbounded bodies are G-11/G-05. |
| `internal/plugin/builtin/cloudflare/cloudflare.go` | Optional HTTPS requests to `https://api.cloudflare.com/client/v4` using a bearer token. | Authenticates the cloud storage API, not a WireGuard peer. It is included by `builtin_all` and absent from an OpenDHT-only build. |
| `internal/plugin/dialer/dialer.go` | Configured proxy/STUN hostname resolution over the underlay DNS servers. Android fallback resolvers are `8.8.8.8`, `1.1.1.1` and `2001:4860:4860::8888` in `mobile/node.go`. | DNS can reveal names and affect availability, but does not authorize a peer. |
| `internal/ctrl/ping_monitor_linux.go` and platform analogues | Optional ICMP health probes over a configured WireGuard device. | Health monitoring is not a peer authenticator; packets remain governed by the interface's routing/authentication. Linux raw ICMP requires socket privilege if enabled. |
| `internal/plugin/exec.go`, `shell.go` | Optional configured child processes receive a storage request by stdin and return a storage response on stdout. | Local configuration/import controls the executable. Child process code runs with the container/user's available permissions; G-06 recommends removing it from a minimal build. |
| `internal/wg/client_cli.go` | Optional `wg` command-line backend reads `wg show ... dump` and runs `wg set ... peer ... endpoint` with an argument vector. | Reads the WG static private key into daemon memory. It does not interpolate the discovered endpoint into a shell command. `wgctrl` is the other desktop backend. |
| `internal/crypto/endpoint.go` | NaCl box encrypts/decrypts public-store endpoint records using WG static X25519 keys. | This is a second record authenticator outside WG and without the WG PSK (G-02), with a low-order-key exception (G-14). |

The production source scan found no analytics, crash-reporting or general telemetry client endpoint. The default public STUN host (`stun.l.google.com:19302`) and optional Cloudflare API are intentional documented integrations; the OpenDHT proxy is user-configurable (the Android UI suggests `https://dhtproxy2.jami.net`). This inventory does not certify the absence of a backdoor in compiled dependencies, dynamic network data, a different build tag, or a later commit. The main report records release-artifact comparisons and dependency hashes separately.
