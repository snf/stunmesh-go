# Advisory triage after remediation — 2026-09-22

`advisory-scan.json` contains 551 OSV coordinate queries across the **full** Go and Gradle resolution graphs, including optional build/test tools. `advisory-index.json` records finding IDs and upstream references. Counts are not exploit counts. Package inventories are in `mobile-packages.txt`, `server-packages.txt`, `gomobile-packages.txt` and `android-runtime-dependencies.txt`. This review finds no newly reported affected package on the shipped Go/Android paths; it does not claim no undiscovered vulnerabilities or compromised dependencies.

Alpine source is **3.23.5**. Only BusyBox `1.37.0-r30` and musl `1.2.5-r23` are retained; `alpine-security.json` preserves the matching [3.23 security database](https://secdb.alpinelinux.org/v3.23/main.json). Both versions include every fix listed there on this date. The static `wg` tool is compiled from the signature-verified official archive; the Go daemon uses a static build. The host kernel/WireGuard driver, Podman/pasta and Android OS are separate deployment dependencies that must be checked on the actual devices.

All 839 pinned Gradle artifact hashes matched publisher data (181 reuse earlier independently checked audit evidence). This checks distribution consistency; a compromised publisher could distribute consistently malicious bytes. Offline builds, no release CI, bounded network parsers, removing custom crypto/process plugins, and isolating signing reduce that risk without claiming to eliminate it. No blanket dependency upgrade was justified by these reachability findings.
